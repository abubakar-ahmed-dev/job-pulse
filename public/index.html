JobPulse Architecture & User Guide

What does JobPulse do?

JobPulse continuously ingests software engineering opportunities from authoritative remote sources (WeWorkRemotely) using strict ethical crawling, then deploys a production-guarded LLM inference layer to classify roles into high-signal engineering attributes.

Step 1: Explore & Filter

Unified Architecture: Polite Scraper (W5) + Guarded LLM (W7)

JobPulse eliminates un-guarded brittle LLM scripts by wrapping every pipeline boundary in strict validation schemas, isolation policies, and fallback routines.

W5 Polite Harvester
  • Robots.txt Compliance: Scrapes target allowed paths with identified custom User-Agent.
  • Rate Limiting & Timeout: 500ms delay between fetches with 5000ms socket timeouts.
  • Local Disk Caching: SHA-256 hashed disk cache avoids redundant bandwidth.
  • Cryptographic Receipts: Every listing retains canonical_url, source_page, and ISO timestamp.
W7 Guarded LLM API
  • Fast-Fail Input Shield: Rejects payloads with < 20 chars or missing fields (HTTP 400) before spending model quota.
  • 30-Second Hard Timeout: Overrides 10-minute SDK defaults to protect queue depth.
  • Exponential Backoff + Jitter: Automatically handles 429 & 5xx; never retries 400, 401, or 403.
  • 1x Automated Repair Retry: Repaired schema feedback loop rescues malformed JSON.
  • Quarantine Ledger: Fatal payloads isolated into logs/quarantine.jsonl.
  • Emergency Kill Switch: LLM_ENABLED=false flips to safe deterministic heuristics.

API Endpoints Reference

JobPulse exposes production Express endpoints suitable for programmatic integration.

  -H "Content-Type: application/json" \
  -d '{
    "title": "Senior Go Backend Architect",
    "company": "Nexus Systems",
    "description": "Building distributed event pipelines with Go, Kafka, and PostgreSQL. Remote."
  }'
